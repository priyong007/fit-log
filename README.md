Project Name: FitLog

Description:
FitLog is a workout management web application where users can explore workouts, add exercises to their daily workout plan, save workouts for later, and manage their selected exercises easily.

Technologies Used:
JavaScript, TypeScript, Next.js, App Router, Tailwind CSS, DaisyUI, React Toastify

Features:

Add workouts to today’s workout plan
Save workouts for later
Delete workouts from the plan
Display total selected workouts
Fetch workout data from an API
Responsive and user-friendly interface
